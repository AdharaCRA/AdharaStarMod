# Cloud-Rain Interstellar Engineering Mod
A Java Mindustry mod template that works on Android and PC.

## Description -- 描述
This is the first mod that made by AdharaCRA. It runs based on Mindustry.

The mod is in the initial testing stage,so there are still some problems...

Some functional code may source from other mods like NewHorizon.

However, with the advancement of modding skills, these "borrowed" part will be soon replaced with independently developed codes.

这是AdharaCRA独立开发的第一个Mindustry模组。
它处于初阶测试阶段，所以仍然会有各种各样的问题。

一些功能性的代码可能来自于其他模组，例如New Horizon新视界 等。不过随着制作技术的进步，这些“借鉴”引用的部分后续将会改为自主研制的代码。
